# Hive War 核心体验陈述

## 一句话版本

玩家不是操控某一只单位，而是作为“宏观意志”，通过参数、信标与资源分配，塑造一支会自我竞争、淘汰、融合、进化并争夺据点的赛博蜂群。

## 体验目标

1. **观察涌现**：大量单位在少量规则驱动下形成可读的群体行为。
2. **宏观调控**：玩家通过阈值、信标、基地与变异率，而不是微操单体。
3. **进化取舍**：数量、质量、成长节奏、占点效率之间持续拉扯。
4. **风格塑形**：不同基因池与信标策略会逐渐塑造出不同“族群性格”。

## 当前原型边界

- 已实现：基因池、升级、进化、融合、流场移动、空间哈希战斗、信标、基地占领、生物质经济、HUD、粒子表现。
- 暂未实现：音频、关卡目标体系、扩展脚本层、完整数值平衡、内容包化生产流程。

## 设计原则

- **单位不可微操**
- **状态要能被看懂**
- **参数要能被调出风格**
- **玩法核心优先于题材包装**
