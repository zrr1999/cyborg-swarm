# 基地、占领与信标

## 基地职责

- 作为单位出生点。
- 作为战线锚点与流场目标。
- 作为生物质收入来源。
- 作为战局翻转的关键节点。

## 占领规则

- 敌方单位进入基地占领半径后，对基地持续造成压制伤害。
- 基地生命值归零后，按附近优势阵营翻转控制权。
- 基地翻转后恢复部分生命值，并重新成为对应阵营的出生点与流场目标。

## 当前地图点位

- 玩家主基地：左侧
- 敌方主基地：右侧
- 中立基地：中路、上路、下路各一处

## 生物质经济

- 每个已占领基地持续产出生物质。
- 生物质用于支撑单位生产与后续宏观决策成本。
- 当前原型先验证“基地越多，节奏越快”的正反馈是否过强。

## 信标类型

| 类型 | 作用 |
| --- | --- |
| 吸引信标 | 拉动己方单位向目标区域聚集 |
| 排斥信标 | 让己方单位绕开危险区域 |
| 优先目标信标 | 强化局部推进与集火倾向 |

## 交互约束

- 玩家只影响趋势，不直接给单体下命令。
- 信标应当“改变走势”，而不是变成硬传送或硬控制。
