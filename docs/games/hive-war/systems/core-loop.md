# 核心循环

## 玩家每局的主循环

1. 基地依据当前基因池生成新单位。
2. 单位沿流场推进，并受信标影响产生局部偏转。
3. 单位进入感知范围后交战、受伤、死亡并累积经验。
4. 满级单位触发进化或在条件合适时融合。
5. 阵亡样本与存活样本共同回写基因池，影响后续出生质量。
6. 基地被持续压制后发生占领翻转，控制权变化进一步改变战局与资源流向。

## 玩家核心操作

- 放置信标：改变局部推进方向或优先目标。
- 调节参数：变异率、基因池权重等。
- 争夺基地：通过宏观布势让蜂群形成局部优势。

## 关键张力

- **短期战力 vs 长期基因质量**
- **抢中立点 vs 保己方后场**
- **扩大数量 vs 压缩精英化**
- **稳定生长 vs 高波动突变**

## 当前原型验证目标

- 蜂群是否能在低操作负担下表现出明显差异化行为。
- 参数调节是否会真实改变族群的战斗风格。
- 占点与成长是否能形成可持续的滚雪球与反滚雪球。
