# 进化与遗传系统

## 当前遗传属性

| 属性 | 作用 |
| --- | --- |
| `max_health` | 最大生命值 |
| `attack` | 单次伤害 |
| `speed` | 移动速度 |
| `sensor_range` | 感知与接战范围 |
| `armor` | 伤害减免 |
| `attack_speed` | 攻速倍率 |

## 生命周期

1. **出生**：基地按基因池均值与变异率生成新单位。
2. **成长**：作战获得经验并升级。
3. **进化**：满级后按优势属性归类为战术职业，并重置到新一轮成长。
4. **融合**：两个满足条件的满级单位可融合为更高质量后代。
5. **死亡**：死亡样本进入滚动窗口，参与后续出生均值计算。

## 战术职业

| 职业 | 倾向 |
| --- | --- |
| Drone | 平衡型 |
| Siege | 攻击偏置 |
| Vanguard | 生存偏置 |
| Scout | 机动偏置 |
| Sentinel | 感知偏置 |
| Hive | 攻速偏置 |

## 基因池规则

- 存活样本与近期死亡样本共同决定出生均值。
- 死亡窗口保留“失败经验”，避免种群只记录当前幸存者。
- 融合产物不被视为常规死亡惩罚，以鼓励玩家主动做质量交换。

## 当前调参重点

- 变异率是否足够制造差异，但不会破坏可读性。
- 进化增益是否足够明显。
- 融合收益是否覆盖数量损失。
