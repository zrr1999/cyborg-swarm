# Squad Strike 核心体验陈述

## 一句话版本

玩家直接拖动一支小队队长，在持续来袭的敌群中边打边成长，体验更近距离、更快节奏的生存战斗。

## 体验目标

1. **直接操控**：与 `hive-war` 的宏观调控不同，这里强调队长牵引与即时位移。
2. **短周期成长**：波次、击杀与升级反馈要比占点对局更紧凑。
3. **小队协同**：队长与跟随者之间应有清晰编队与支援感。
4. **生存压迫**：玩家持续面对敌潮压力，而不是经营多基地战线。
